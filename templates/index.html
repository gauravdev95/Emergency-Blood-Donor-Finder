How it works (DSA pipeline)

Request → HashMap (blood group) → availability filter → distance (Dijkstra road route, else Haversine) → Min-Heap → nearest-first list.

Example from the brief: a patient in Agra needing O+ gets compatible donors (O+ and O−) ranked by distance — e.g. Sikandra, Kamla Nagar, Dayal Bagh — with incompatible groups filtered out.
